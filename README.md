# 🌿 Ingredient Checker

A simple web app that checks food ingredients and alerts users about harmful components like palm oil and maida.

## 🚀 Features
- Detects palm oil and its hidden names
- Detects maida (refined flour)
- Simple and user-friendly interface

## 🧠 How it works
Paste ingredients into the app and click "Check".  
The app will tell you if any harmful ingredients are present.

## 💻 Tech Used
- Python
- Streamlit

## 🌱 Purpose
This project helps people make safer food choices, especially those with allergies.
